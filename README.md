# simple-log

Self-hosted editing software with offline/realtime syncing for [log.roadtolarissa.com](https://log.roadtolarissa.com/).

Point [Claude Code](https://claude.com/claude-code) at this repo, grab a $5/month VPS and install the PWA for an MVP gdocs where you have complete control over the interface. No more giant sticky editing bar or [futzing converting to markdown](https://github.com/1wheel/doc2txt)!
